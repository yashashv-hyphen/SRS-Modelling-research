# Working-paper figures

Code that computes and draws the charts in [`docs/working-paper.html`](../../docs/working-paper.html)
("Who Should Use Singapore's Supplementary Retirement Scheme — and Who Shouldn't?").

Each script imports the models from the repository root (`srs_model.py`, `srs_simulation.py`)
and writes JSON or SVG/HTML into `out/`, which is git-ignored and safe to regenerate. The charts
are hand-rolled inline SVG with no plotting library. They use the paper's CSS variables
(`--c-main`, `--c-second`, `--c-third`, …), so they render correctly only inside the paper's
stylesheet.

```bash
./run_all.sh            # or: PYTHON=.venv/bin/python ./run_all.sh
```

Running the full pipeline on this branch reproduces every computed chart byte-for-byte against the
published paper.

## Data scripts (run first)

| Script | Produces | Feeds |
|---|---|---|
| `sweeps.py` | `out/sweeps.json`: one-factor sweeps of `srs_model.run()` | Figs 9–13, Tables 6–7 |
| `data_sweeps_dp.py` | adds the DP grid-solver tax to `sweeps.json` | Fig 13, Table 6 |
| `data_flat_market.py` | `out/flat_market_v2.json`: three strategies at a flat 5% return | Fig 7c |
| `data_volatile_path.py` | `out/strategy3_v2.json`: three strategies on an S&P 500 block-bootstrap path (seed 17) | Fig 7b, Table 3 |
| `data_fig7.py` | `out/fig7_corrected.json`: level withdrawal per (balance, years left) and its marginal rate | Fig 7 |

## Chart scripts

| Script | Draws |
|---|---|
| `gen_main.py` | Fig 6: Model 1 MAIN heatmaps, return × tax rate, 2×2 (horizon, ending balance) |
| `gen_crossover_lines.py` | Fig 6b: indifference-boundary line per Fig 6 panel |
| `gen_fig7_corrected.py` | Fig 7: Model 2 MAIN withdrawal-policy grids at four non-SRS incomes |
| `gen_final_three.py` | Figs 7b, 7c, 13: DP vs level drawdown vs the $40k rule |
| `gen_charts.py` | Figs 9–12: sensitivity panels (return, bracket, years, other income, exit-rate staircase) |

`gen_main.py` also draws an earlier, grid-search version of the Model 2 panels. The paper uses the
corrected closed-form panels from `gen_fig7_corrected.py` instead. `gen_charts.py` likewise writes
an earlier Figure 13 that `gen_final_three.py` replaces.

## Not generated by code

Figures 1–5 and Figure 8 are small SVGs written by hand into the paper. Their numbers come from
`docs/findings.md` (§5, §7, §8, §12, §14) and `results_tax_regime.json`. Figure 7b's
oi = 0 withdrawal series is hardcoded in `gen_final_three.py`; `data_volatile_path.py` prints
the identical series from the model.
